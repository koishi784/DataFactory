# 数据工厂管理系统

基于 Umi Max + React + TypeScript + Ant Design 构建的数据工厂管理平台前端项目。

## 功能模块

- **用户系统**：登录、注册、个人信息管理
- **数据源管理**：接口管理、人工注册、数据库管理
- **数据标准管理**：数据标准目录、码表管理
- **数据资产管理**：资产表查看与管理
- **脚本管理**：数据处理脚本管理
- **任务管理**：数据任务调度与管理

## 技术栈

- 框架: Umi Max 4
- UI 库: Ant Design 5 + Pro Components
- 语言: TypeScript 5
- 包管理器: pnpm
